# Job Tracker — 功能规格书

## 1. 产品概述

- **一句话定位**：求职全流程进度记录与自动化追踪工具
- **目标用户**：正在求职的个人用户，需要系统性管理投递记录、追踪面试进度
- **核心价值主张**：告别 Excel 手记，让求职进度自动化录入、可视化追踪、Gmail 双向联动

## 2. 功能清单

### P0 — MVP 必需

| 功能模块 | 描述 | 验收标准 |
|---------|------|---------|
| 手动录入 | 用户填写岗位名称、公司名称等字段新增记录 | 最少填 2 个必填字段即可创建记录，列表即时刷新 |
| 列表展示 | 按主状态 Tab 分组展示所有记录，子状态以徽章显示 | 三个 Tab 可切换，每条记录显示关键字段摘要 |
| 标签切换 | 支持两级状态机的手动流转 | 用户可修改任意记录的主状态和子状态，状态即时更新 |
| 本地持久化 | 所有数据存入本地浏览器存储 | 刷新页面后数据不丢失，关闭重开仍存在 |
| 搜索筛选排序 | 按岗位名/公司名模糊搜索，按状态筛选，按时间排序 | 搜索框输入即时过滤，排序按钮切换升降序 |

### P1 — 后续迭代

| 功能模块 | 描述 | 优先级 |
|---------|------|-------|
| 截图 OCR 录入 | 上传 JD 截图，自动提取岗位信息并填充到表单 | 阶段 2 |
| 附件管理 | 截图/文件上传并与记录关联，支持查看和删除 | 阶段 2 |
| Gmail 接入 | OAuth 授权后扫描发件箱+收件箱，自动匹配求职邮件 | 阶段 3 |
| 统计面板 | Dashboard 展示投递数、面试率、Offer 率、饼图 | 阶段 4 |
| 无回应自动提醒 | 超过设定天数未回复的记录，系统提示建议标记 | P2 |
| 邮件回复类型识别 | 自动识别面试邀请/拒信/Offer 并提示更新状态 | P2 |

## 3. 用户故事

### 故事 1：求职者想要新增一条投递记录
**Given** 用户打开应用  
**When** 用户点击「新增记录」并填写岗位名称和公司名称  
**Then** 新记录出现在「进行中」Tab 下，子状态显示为「已发送求职邮件」

### 故事 2：求职者想要更新面试进度
**Given** 用户有一条「已发送求职邮件」的记录  
**When** 用户收到面试邀请，手动将子状态改为「等待第 N 轮面试」并输入 N=1  
**Then** 记录子状态更新，徽章显示「第 1 轮面试」

### 故事 3：求职者想要查看整体统计
**Given** 用户已录入多条不同状态的记录  
**When** 用户切换到 Dashboard 视图  
**Then** 看到总投递数、面试中数量、Offer 数量、饼图和最近活动时间线

### 故事 4：求职者想要通过截图快速录入
**Given** 用户有一个招聘页面的截图  
**When** 用户上传截图，系统 OCR 提取信息后展示预览  
**Then** 用户确认后自动创建记录，截图保存为附件

## 4. 数据模型概览

### 核心实体

**JobApplication（求职记录）**
- 岗位名称（必填）
- 公司名称（必填）
- 职位描述 JD（可选）
- 投递链接（可选，可多个）
- 招聘者邮箱（可选，可多个）
- 简历版本（可选）
- 求职邮件发送时间（可选）
- 面试时间（可选，可多条）
- 对方回复时间（可选，可多条）
- 主状态：进行中 / 暂停 / 已结束（必填）
- 子状态：已发送 / 等待面试 N / 面试完成 / 待定 / Offer / 已入职 / 已拒 / 无回应 / 放弃（必填）
- 面试轮次 N（条件必填）
- 附件列表（可选）
- 备注（可选）
- 创建时间（自动）
- 最后更新时间（自动）

**Attachment（附件）**
- 所属记录 ID
- 文件名
- 文件类型
- 存储路径/Base64
- 上传时间

**ActivityLog（活动日志）**
- 所属记录 ID
- 动作描述（如"状态从已发送变为等待面试"）
- 时间戳

### 实体关系

```
JobApplication 1 ──── * Attachment
JobApplication 1 ──── * ActivityLog
```

## 5. 非功能性需求

- **性能**：本地存储操作 < 50ms 响应；列表渲染 500 条记录无卡顿
- **安全**：Gmail OAuth 使用 PKCE 流程；不存储邮件正文到本地，仅存索引信息
- **兼容性**：支持 Chrome 最新版、macOS 环境
- **可用性**：离线可用（Gmail 扫描和 OCR 除外）；UI 响应式，适配 1024px 以上宽度
- **数据可迁移**：支持导出全部记录为 JSON/CSV
